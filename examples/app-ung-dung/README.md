# App theo chương Ứng dụng 1–3

Code đúng như sách viết ở ba chương Ứng dụng: khung app, trang chủ, đăng nhập. Dùng để đối chiếu khi bạn tự gõ.
Bản đầy đủ của app nằm ở `app/`. Hai thư viện `hugo-music` và `hugo-stream` cài từ npm (`pnpm install` ở gốc repo).

```bash
cp ../../app/.env.example .env      # điền URL và publishable key của project bạn
npx expo start --web
```
